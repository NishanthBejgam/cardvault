Import cards

Paste one card per line. Separate fields with commas, in this order:

Bank, Card name, Number, Holder, Expiry, CVV, Network, Variant, Add-on, Relation

Only Bank and Card name are required — leave the rest blank (just keep the commas) and fill them in later. The last Add-on column marks family cards: put add-on (or yes) to make it an add-on of the primary card with the same name, or leave it blank for a primary card. Relation says whose card it is (Self, Spouse, Father…); blank means Self. A header row is ignored.

Settings

On this phone

…

Your cards live in this app's private storage, encrypted with your master password. Uninstalling the app deletes them, so keep an export somewhere safe.

Auto-lock

When to lock the vault after you switch to another app. Copying a card number usually means a trip to another app and back, so this is not set to lock instantly.

Whatever you choose, the card list is never shown in the recent-apps preview, and the vault always locks when the app is closed.

Fingerprint unlock

Opens the vault with your fingerprint instead of typing the master password. Your password is kept in this phone’s secure store and released only on a match.

Master password

Change the password that encrypts your cards. You need the current one.

Backups you exported earlier still open with the password they were made with.

Relations

Who a card can belong to. These are the choices offered when you add or edit a card, and the views you can switch between on the home page. Add your own — Wife, Dad, Friend, Business Partner — and remove the ones you never use.

A relation that is still used on a card cannot be removed until those cards are moved to another one. Self is always kept.

Export

Saves an encrypted copy you can share to Drive, mail or a cable. It is the same file format the Windows and Mac apps use, so it can be opened there too — with this same master password.

Changing phones?

Your cards do not move by themselves. Four steps:

  1. Export above and send the file somewhere you can reach from the new phone: Drive, email, or a chat to yourself.
  2. Install Card Vault on the new phone with the same Google account. You have already bought it, so it will not charge again.
  3. Create a vault there. Using the same master password keeps things simple.
  4. Import the file below on the new phone, with the password it was exported with. Then turn fingerprint unlock on again.

The same file also opens in Card Vault on a Windows PC, a Mac or an iPhone.

Open a vault.dat from your PC or Mac, or a backup exported from another phone.

How your cards are protected

  • Nothing central to hack. There is no account, no server and no cloud copy of your vault.
  • Strong encryption. Your cards are kept in one AES-encrypted file with a tamper check, locked with a key made from your master password.
  • Fingerprint unlock lives in the secure chip. If you turn it on, your master password is kept in the phone’s secure hardware and released only on a fingerprint match.
  • No internet access. The internet permission is removed from the app, so Android itself blocks any network connection.
  • It never leaves on its own. Android cloud backup and phone-to-phone transfer are turned off for this app, and debugging is off.
  • Hidden from view. Screenshots, screen recording, screen sharing and the recent-apps preview are blocked. Apps that misuse accessibility cannot read the vault, and other apps cannot draw over it while it is open.
  • Only Card Vault’s own code runs. A file you import can add cards, never run anything.
  • The small things too. Card numbers are masked until you tap and hide again after 45 seconds, copied numbers clear from the clipboard after 45 seconds, the CVV is left out of shared details unless you include it, and card scanning runs offline on the phone.
